# Degerliyuvam Mobile

Flutter mobile client for the Degerliyuvam platform.

## API Base URL

Use `API_BASE_URL` when running on a physical device or emulator.

Example:

```bash
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:5000
```

## Included

- Premium dark/gold theme
- Home, listings, listing detail, messages, profile, seller panel
- Session-based API client
- Local asset reuse from the existing web project
